# 참고 링크

## 공식 문서

- [Git 공식 사이트](https://git-scm.com/) — 다운로드, 문서, 레퍼런스 전부 여기서 시작
- [Git 레퍼런스 매뉴얼](https://git-scm.com/docs) — `git <command> --help`와 동일한 내용을 웹에서
- [Pro Git (한국어판, 무료)](https://git-scm.com/book/ko/v2) — Git 공식 교재. 특히 10장 "Git 내부"가 이번 강의의 objects/refs/HEAD 내용과 바로 연결됨
- [GitHub Docs](https://docs.github.com/) — GitHub 자체 기능(PR, Actions, 원격 저장소 설정 등) 관련 공식 문서

## 학습/실습 자료

- [Learn Git Branching](https://learngitbranching.js.org/) — 브랜치·rebase·cherry-pick을 그래프로 직접 조작하며 배우는 인터랙티브 사이트
- [Oh Shit, Git!?!](https://ohshitgit.com/) — 실수했을 때(되돌리기, reflog 등) 상황별 해결법 모음
- [Atlassian Git Tutorials](https://www.atlassian.com/git/tutorials) — merge/rebase, 워크플로 등을 그림과 함께 설명
- [Git Cheatsheet (ndpsoftware)](https://ndpsoftware.com/git-cheatsheet.html#loc=index) — Workspace/Index/Local/Remote 사이를 오가는 명령어를 시각적으로 정리한 치트시트 (2-1에서 다룬 5가지 영역과 바로 연결됨)

## 심화 주제

- [Pro Git — Git Internals](https://git-scm.com/book/en/v2/Git-Internals-Plumbing-and-Porcelain) — objects, refs, packfile 등 3장에서 다룬 내부 구조의 원문
- [Git Submodules 공식 가이드](https://git-scm.com/book/en/v2/Git-Tools-Submodules) — 7-2에서 다룬 submodule의 더 자세한 사용법
- [Git Worktree 공식 문서](https://git-scm.com/docs/git-worktree) — 7-1에서 다룬 worktree의 전체 옵션
