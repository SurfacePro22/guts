# Git과 GitHub, 뭐가 다른가

## 한 줄 정의

- **Git**: 내 컴퓨터에서 동작하는 버전 관리 소프트웨어 (인터넷 없어도 동작)
- **GitHub**: Git 저장소를 올려두는 웹 서비스. PR, Issue, Actions 같은 부가기능을 얹은 플랫폼 (Microsoft 소유)

비유: Git = 동영상 파일(카메라·편집 프로그램으로 만들어서 내 컴퓨터에 저장, 유튜브 없이도 재생 가능), GitHub = 유튜브(그 영상을 올려서 사람들과 공유하고 댓글·조회수 같은 부가기능을 붙이는 서비스). "동영상에 올린다"가 아니라 "유튜브에 올린다"고 말하듯, "git에 올린다"가 아니라 "github에 올린다(push한다)"가 맞는 표현이다.

## 표로 비교

| | Git | GitHub |
|---|---|---|
| 정체 | 버전관리 소프트웨어 | 저장소 호스팅 서비스 |
| 만든이 | 리누스 토르발스 (2005년, 리눅스 커널 개발용으로 제작) | 톰 프레스턴워너 등이 2008년 창업, 2018년 Microsoft가 인수 |
| 설치 | 필요 | 불필요 (웹/계정) |
| 동작 위치 | 로컬 (오프라인 가능) | 서버 (인터넷 필요) |
| 대체재 | 사실상 없음 | GitLab, Bitbucket, Gitea 등 |
| 관계 | GitHub 없이도 완결됨 | Git 없이는 성립 불가 |

## 한 줄 요약

Git = 버전관리 **도구**, GitHub = 그 도구로 만든 저장소를 올리고 협업 기능을 더하는 **서비스** 중 하나.
